# The joke about the demo

A tiny program for the make.fun bounty "The joke about the demo".

Running `main.py` (Python 3.13) writes one original one-line joke about
working beside AI coding agents to `/output/entry.txt` — no network, no
arguments, no extra files. The joke is a single line, 1–280 characters.
